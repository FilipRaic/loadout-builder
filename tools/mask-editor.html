Tips

To fix a bleed, pick the item that should be there, then start your stroke inside the wrong colour and paint over it. With "Only repaint the item I start on" enabled, neighbouring items won't get damaged.

Fill is quickest for a whole blob that got the wrong item (e.g. background between legs).

"Unchanged" = parts that always keep the photo's look (rifle, glasses, flags…). "Background" is also left untouched.
Open the project folder to start

Click Open project folder… and choose C:\Projects\loadout-builder.
Allow the browser to edit files when asked. The editor reads the photos and item maps from that folder and saves your fixes back into it.

Needs Chrome or Edge (Firefox can't write to folders).
